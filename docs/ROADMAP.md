# Delivery Roadmap

## Phase 0 — Decisions and setup

Resolve `DECISIONS.md`, obtain official brand assets, confirm framework conventions, initialize Git/GitHub/Supabase/Vercel, and define environments and branch protection.

Exit: product rules and technical baseline are approved.

## Phase 1 — Foundation

Scaffold React, design tokens, Supabase authentication/clients, SQL migrations/RLS/seed data, CI, and preview deployment.

Exit: authenticated guest/staff shells and tested RLS work in preview.

## Phase 2 — Guest MVP

Build the mobile card, milestones, reward details, history, profile, member code, complete UI states, responsive behavior, and accessibility coverage.

Exit: a seeded guest can sign in and understand their full loyalty state on mobile.

## Phase 3 — Staff MVP

Build desktop staff search/scan, guest record, transactional visit/reward issuance, redemption, manager corrections, audit view, and concurrency/idempotency tests.

Exit: the complete in-spa workflow passes acceptance tests.

## Phase 4 — Hardening and launch

Complete security/privacy/accessibility/performance reviews; configure monitoring, backups, and support runbooks; run a staff pilot; fix issues; approve rollout.

Later opportunities include phone OTP, wallet passes, POS/booking integration, multi-location reporting, referrals, analytics, and promotions.
